How to work with Phluux

Phluux delivers trusted machine learning for physical assets through three paths: use Phluux Studio yourself, engage us for managed delivery, or start with managed and transition to the platform. All three use the same learning system and deployment approach.

Platform

Use Phluux Studio

License Phluux Studio and run the complete learning-to-deployment workflow yourself. Full access to the platform, with support and training available.

Who it's for

Teams that want to build and deploy inference models themselves, with full control over the workflow. Suitable for organizations with ML expertise or those building internal capabilities.

What's delivered
  • Phluux Studio platform access
  • Training and documentation
  • Support for platform usage
  • Ability to deploy models you build
Typical engagement

Platform license with onboarding and training. Ongoing support available. You own the workflow end-to-end.

Managed

Managed Inference Delivery

Phluux delivers inference models and runtime packages using the same learning system. We handle the workflow; you get deployment-ready models.

Who it's for

Organizations that want inference delivered without building internal ML capabilities. Suitable for focused pilots, rapid deployment, or when expertise is better applied elsewhere.

What's delivered
  • Validated inference models
  • Versioned runtime packages
  • Deployment support
  • Monitoring configuration
  • Documentation and handoff
Typical engagement

Pilot engagement (8-12 weeks) to validate approach and deliver first model. Can extend to multiple assets or ongoing support.

Hybrid

Hybrid approach

Phluux sets up the first deployment using managed delivery, then transitions you to Phluux Studio for ongoing work. Best of both worlds.

Who it's for

Organizations that want to start with managed delivery to validate the approach, then build internal capabilities using the platform. Lowers initial risk while building long-term capacity.

What's delivered
  • Initial managed delivery (pilot)
  • Phluux Studio access
  • Knowledge transfer and training
  • Transition support
Typical engagement

Managed pilot (8-12 weeks) followed by platform license and transition. You take over ongoing work in Studio.

All paths use the same system

Whether you use Phluux Studio yourself or engage us for managed delivery, you get the same learning system: coverage-driven scenarios, acceptance criteria upfront, full-envelope validation, and deployment-ready runtime packages. The difference is who runs the workflow.

Not sure which path is right?

We can help you choose based on your goals, timeline, and internal capabilities.
