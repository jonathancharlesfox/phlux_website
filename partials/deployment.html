Production readiness

Deployment is not an afterthought. Every model is packaged as a versioned runtime with schemas, preprocessing, and monitoring hooks. Trust in production comes from validity envelopes, monitoring, and versioned releases.

Runtime packaging

Every deployment includes a complete runtime package: input/output schemas, preprocessing pipelines, model artifacts, and version metadata. This ensures that behavior is repeatable across environments and that deployments are traceable.

The Model Passport documents what was validated, where it's valid, and how to monitor it. This is not just a model file — it's a complete deployment package.

Deployment deliverables

  • Versioned runtime package (schema + preprocessing + model)
  • Model Passport (validation results, operating envelope)
  • API endpoints or integration hooks
  • Monitoring configuration (drift + reliability)
  • Documentation and handoff materials

Deployment options

Phluux can be deployed in the environment that best fits your IT/OT constraints — from a small-footprint on-prem runtime near the data source to centralized cloud deployments for fleet-scale rollout.

On-prem / edge

Inference runs entirely within the customer's network, either on existing servers or a dedicated small-footprint compute device installed on site. Suitable for air-gapped environments or low-latency requirements.

Cloud

Inference runs in a centralized cloud environment. Suitable for portfolio-level deployments where data can be securely transmitted off-site. Enables fleet-scale rollout and centralized monitoring.

Integration capabilities

Every deployment is designed for reliable integration into existing workflows, whether through REST APIs, edge runtimes, or embedded OEM integrations.

API endpoints

Flexible REST endpoints for inference, health checks, and version discovery. Stable, versioned schemas with validation and clear error responses.

Versioned schemas

Stable, versioned input/output schemas with validation. Changes are versioned and backward-compatible where possible.

Runtime bundles

Complete runtime packages that include preprocessing + model artifacts. Behavior is repeatable across environments.
