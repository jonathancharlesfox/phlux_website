Platform Architecture

Phluux Studio is a modular, cloud-native platform composed of independently deployed web, orchestration, and runtime services. The platform is accessed through a browser-based interface and, depending on deployment configuration, optional programmatic APIs to support automated inference workflows. All execution occurs in the cloud using managed, containerized runtime services. Users submit feature values to the platform, inference is executed within the managed environment, and predictions are returned through secure, scalable interfaces. This architecture prioritizes reliability, scalability, and integration while maintaining a consistent user experience.

Key capabilities

  • Enterprise-grade authentication and access control
  • Cloud-native managed execution environment
  • Containerized runtime services
  • API-driven integration interfaces

Deployment Options

Phluux Studio is a managed, cloud-based platform used to build and package trained models into containerized inference runtimes. Once packaged, the container image is pushed to a registry and can be deployed in different environments based on your IT/OT requirements. The containerized inference runtime is portable and can execute wherever your deployment constraints require.

Managed Cloud Inference (Phluux-Hosted)

The inference container is deployed and run within the Phluux-managed cloud environment. Phluux exposes secure inference endpoints (APIs) that you send feature values to and receive predictions from. This option provides the simplest deployment path with no infrastructure management required on your side.

Customer-Managed Deployment (BYO Runtime)

Pull the container image from the registry and deploy it into your own cloud, edge, or internal infrastructure using your existing tooling and pipelines. You maintain full control over where and how the inference runtime executes, while leveraging Phluux Studio for model development and packaging.

On-Premises Deployment (Phluux-Supported)

Phluux can deliver and install the inference container on customer-provided or Phluux-provided hardware within an on-premises environment, with no dependency on cloud execution. This option is suitable for restricted or regulated environments where data cannot leave your network.

Scalability, Security & Integration

Scalability

Phluux Studio is designed to support scalable execution of inference workloads through containerized runtime services deployed in the cloud. The platform can accommodate increasing inference demand by running multiple instances of the inference runtime, enabling consistent performance as usage grows.

Security

Phluux Studio incorporates role-based access controls and environment-level isolation to ensure users can only access authorized projects and data. The platform leverages cloud-native security mechanisms for authentication, network isolation, and data protection, with encryption applied during data transmission and storage within the managed environment.

Integration

Phluux Studio supports integration through programmatic interfaces where enabled, allowing inference runtimes and workflows to connect with external systems. Containerized inference outputs are designed to be portable and deployable into existing customer environments, enabling integration with established data pipelines and operational systems without requiring changes to the core platform.
